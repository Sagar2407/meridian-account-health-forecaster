# Module 7 Capstone Requirements

Source: user-provided Canvas text reviewed on 2026-08-31. This is a normalized repository copy of the actionable requirements, not a claim that a separate criterion-level grading rubric was supplied.

## Learning outcomes

1. Develop an agentic AI autonomous system that addresses a genuine problem.
2. Integrate program components into a cohesive autonomous system.
3. Present the integrated system and its evaluation results to a technical audience.

## Final report

Submit the required report template as PDF or DOCX. It must cover:

- Problem and intended user
- System goal and scope
- Final architecture and major components
- Design evolution across the program
- Implementation overview
- Evaluation methods and results
- Safety, reliability, and human oversight
- Current limitations and future improvements
- Public GitHub repository link

## Public repository

At minimum, the public repository must contain:

- README explaining project, architecture, setup, and usage
- Main code or notebooks
- Supporting sample inputs, outputs, or evaluation artifacts as appropriate
- Clear instructions for running or reviewing the project

The repository must be public, accessible, organized, and understandable to someone outside the program.

## Presentation and video

- Create a presentation using the provided planning outline.
- Record an 8–10 minute presentation for a technical audience.
- Cover the problem, system goal, architecture, major design decisions, evaluation, public repository, strengths, limitations, and next steps.
- Host the video on an accessible platform such as YouTube, Vimeo, or Loom.
- Verify playback, audio, visuals, and sharing permissions.
- Submit a document containing the video link and a two-to-three-sentence summary with the final report.

## Optional elevator pitch

An optional 90-second elevator pitch may be submitted. To be considered for the showcase, the learner must submit the final report, final presentation/video, and elevator pitch.

## Communication standard

The report and presentation must form one cohesive story. They should not read as six weekly assignments placed side by side. Claims should be supported by implementation examples and evaluation results, and the author should be prepared to explain strengths and limitations.

## Data policy

Use only public, synthetic, or anonymized information. Do not include proprietary, confidential, private, or sensitive information from an employer, customers, colleagues, or other individuals.
